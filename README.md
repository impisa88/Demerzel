# Demerzel

This repository contains the public data and ontology artifacts associated with
the manuscript "Demerzel: Context-Aware Behavioral Assessment and Health-Risk
Inference for Wheelchair Users."

The `data` directory contains the constructed context-history dataset and the
aggregate ARIMA metrics. The `ontology` directory contains the OntoDemer OWL and
RDF serializations used by the model.

Participant-level records are not included because written consent for public
data sharing was not obtained.
